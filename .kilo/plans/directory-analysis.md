# 디렉토리 파일 분석 보고서 (Directory Analysis Report)

## 1. 개요
현재 작업 디렉토리(`/root/dglee/removebg`)는 브라우저 기반의 이미지 배경 제거(누끼 따기) 기능을 제공하기 위한 웹 프론트엔드 프로젝트로 확인됩니다. 단일 페이지 애플리케이션(SPA) 형태로 구성되어 있습니다.

## 2. 파일 상세 분석

### `README.md` (10 Bytes)
- 프로젝트의 기본적인 이름(`# removebg`)만 적혀있는 초기 상태의 문서입니다.

### `support.js` (~61 KB)
- `dc-runtime/src/*.ts`에서 빌드되어 자동 생성된 런타임 스크립트 파일입니다.
- React와 ReactDOM을 로드하고, 특수한 HTML 커스텀 태그(`<x-dc>`)를 파싱하여 컴포넌트로 렌더링하는 코어 프레임워크 역할을 합니다.
- 수정하지 않고 그대로 사용하는 파일입니다.

### `누끼컷.dc.html` (~85 KB)
- 실제 화면 UI와 비즈니스 로직을 담고 있는 메인 뷰 파일입니다.
- `<x-dc>` 커스텀 태그를 사용하여 작성되어 있으며, 내부에는 HTML/CSS 구조(Pretendard 폰트 사용)와 함께 데이터 바인딩(`{{ goHome }}`, `{{ appName }}` 등) 문법이 섞여 있습니다.
- 화면은 크게 좌측 내비게이션 바(홈, 보관함 등)와 우측 메인 콘텐츠 영역으로 나뉘어져 있으며, 배경 제거(누끼컷)를 위한 클라이언트 단의 기능 스크립트가 내장된 것으로 판단됩니다.
